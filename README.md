# Ultimate Jogo da Velha

Versão "Ultimate" do jogo da velha, jogável no navegador.

🔗 **Demo:** https://bertmartins.github.io/tic-tac-toe-2./

## 🛠️ Tecnologias

- HTML
- JavaScript

## 🚀 Como executar

```bash
git clone https://github.com/BertMartins/tic-tac-toe-2..git
cd tic-tac-toe-2.
```

Abra o arquivo `index.html` no navegador ou acesse a demo acima.
